📖 Dataset Provenance & Agricultural Research Context

          

          

            

              The sensor measurements reflect 18 vegetable cropping cycles conducted in Flanders, Belgium across 2021 to 2023. 
              Variables include dielectric capacitance millivolts, converted volumetric water content (m³/m³), local pluviometer precipitation, 
              and Penman-Monteith daily Reference Evapotranspiration (ETo).
            

            

              In KrishiRakshak, this research baseline provides grounded truth for real-time sensor simulation, automated drip vs. sprinkler 
              advisory calculations, and machine learning validation.
